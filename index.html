for your TV.

Install APL Launcher from Homebrew for an Apple TV style dock, app grid, folders and cinematic Top Shelf. It installs alongside TV Home, so the original app stays available.

Install APL Launcher

Add the catalog to Homebrew Channel on your TV.
Official Knikt release · v1.3.10
  1. Open Homebrew Channel on the TV and go to Settings → Repositories → Add Repository.
  2. Enter this feed address, save it, then refresh the app list.
https://sono14.github.io/tv-home-hb-repo/apps.json
Project on GitHub View Homebrew catalog
  1. Select APL Launcher and choose Install.
  2. Open APL Launcher from the TV’s app list. If LG asks for permission to control the TV, choose Allow.
Compatibility note: APL Launcher supports LG webOS, but its project does not list webOS 4.5 as a tested TV version. If it does not start, TV Home remains installed. Without root, the TV’s Home button still opens LG Home.

The catalog URL is meant for Homebrew Channel. Opening apps.json in a regular browser displays raw JSON; that is normal. APL Launcher is an independent open-source project by Knikt.
